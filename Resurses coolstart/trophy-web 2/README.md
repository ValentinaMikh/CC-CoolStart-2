# Золотой клевер — модель для веба

Геометрия восстановлена вручную по предоставленному референсу с нескольких сторон. Это визуальная реконструкция, не размерная CAD-копия: изображение не содержит физических размеров, а его ракурсы немного расходятся.

## Файлы

- `trophy.html` — интерактивный просмотр. Открывается прямо в браузере, работает без интернета и внешних CDN. Вращение мышью/пальцем, масштаб колесом/щипком, пять ракурсов, пауза и смена фона.
- `trophy.glb` — самостоятельная модель с PBR-материалами и циклической анимацией `Gentle idle · 8 seconds`. Импортируется в Blender и совместимые веб-движки. Анимацию нужно запустить в принимающем движке.
- `trophy-viewer.js` — собранный модуль Three.js для встраивания, без внешних зависимостей при просмотре.
- `embed.html` — минимальный пример встраивания на прозрачном фоне.
- `src/` и `build.mjs` — редактируемая геометрия, материалы, сцена и сборка.

## Быстрое встраивание

Загрузите `trophy-viewer.js` рядом со страницей:

```html
<div id="trophy" style="width:100%;height:520px"></div>
<script src="./trophy-viewer.js"></script>
<script>
  const trophy = Trophy3D.mountTrophy(document.getElementById('trophy'), {
    autoplay: true,
    shadow: true
  });
  // trophy.setAnimation(false);
  // trophy.setView('front'); // front, back, side, top, perspective
  // trophy.zoom(0.9);
  // trophy.dispose(); // при размонтировании компонента
</script>
```

Канвас прозрачен, поэтому фон задаётся сайтом. `shadow: false` убирает тень. В React/Vue создавайте просмотр после монтирования контейнера и вызывайте `dispose()` при удалении. Высота контейнера должна быть задана явно. Скрипт должен быть разрешён CSP вашего сайта.

Для вставки готового интерфейса целиком:

```html
<iframe src="/trophy.html" title="Золотой кубок — 3D"
  style="width:100%;height:720px;border:0" loading="lazy"></iframe>
```

## Геометрия и материалы

Полая чаша, округлая кромка, ножка и ступенчатое основание; две объёмные ручки; клевер на лицевой и обратной сторонах и на внутреннем дне. Контур клевера выполнен отдельной геометрией по поверхности чаши, без булевого выреза. Это модель для рендеринга, не для 3D-печати.

Вертикаль — Y, лицевая сторона — +Z, основание около Y=0. Высота приблизительно 3 условные единицы. Для реальной высоты 30 см используйте масштаб 0.1, если ваш движок измеряет пространство в метрах. Физический размер исходного кубка неизвестен.

Золото использует metalness/roughness. Для внешнего просмотра GLB нужен студийный свет или environment map: отражения не запекаются в модель. В готовом просмотре окружение создаётся кодом, текстуры не скачиваются.

## Анимация и производительность

Небольшой поворот и плавное приподнимание. После ручного вращения анимация ненадолго затихает; её можно выключить кнопкой. Системная настройка `prefers-reduced-motion` отключает автоматическое движение. Отрисовка пропускается, когда компонент вне экрана или вкладка скрыта. Плотность пикселей ограничена до 1.75.

WebGL 2 обязателен. На iPhone открывайте HTML в Safari: предпросмотр скачанных файлов в приложении «Файлы» может не запускать JavaScript. Производительность зависит от устройства; проверка в эмуляции мобильного экрана не заменяет тест на физическом телефоне.

## Пересборка

Node.js 20+:

```sh
npm install
npm run build
```

Сборка обновляет `trophy.glb`, `trophy-locked.glb`, `trophy.html` и `trophy-viewer.js`. Форма описана в `src/model.js`, свет и управление — в `src/viewer.js`.

Three.js распространяется по MIT; текст лицензии включён в `THREE-LICENSE.txt`.

## Зарядка и конфетти

Короткий клик по кубку вызывает дрожь. Удержание кубка или кнопки в течение 2 секунд запускает золотое свечение, один плавный оборот и конфетти. Раннее отпускание отменяет зарядку, перемещение указателя возвращает обычное вращение. Клавиатура: удерживайте пробел или Enter на кнопке. Вибрация устройства включается только там, где доступен Vibrate API; визуальная дрожь работает независимо от него. При reduced motion остаётся мягкое свечение без дрожи, оборота и конфетти. Эффект реализован в веб-просмотре, GLB содержит исходную модель и idle-анимацию.

## Состояние награды и фирменный логотип

По умолчанию просмотр открывается в состоянии «Не получен»: приглушённое тёмное золото с читаемыми отражениями и логотипом. Удержание 2 секунды переводит кубок в полученное состояние и запускает эффект. Переключатели позволяют сравнить оба состояния. API: `trophy.setUnlocked(true)` / `trophy.setUnlocked(false)`; опция `unlocked: true` включает золото при монтировании. `trophy-locked.glb` — тёмный вариант, `trophy.glb` — полученный.

Фирменный знак построен из путей предоставленного `src/brand-logo.svg`, включая отверстия и обрезку стебля круглой границей. Контуры преобразованы в геометрию, размещены на передней и задней сторонах и дне; исходные зелёный и белый адаптированы под золотой рельеф. Данные контуров: `src/logo-rings.json`.
